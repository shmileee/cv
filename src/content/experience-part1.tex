\cvevent{Senior Site Reliability Engineer}{Two Hundred, consulting for a global SaaS leader in construction IoT}{August 2022 -- Now}{Remote, Denmark}
\begin{itemize}
\item Own the multi-account, multi-region AWS and Kubernetes platform a few hundred engineers ship through, behind a product serving thousands of requests per second. Joined when infrastructure was still changed by hand
\item Moved infrastructure onto infrastructure as code and GitOps delivery: every change is a pull request showing the exact plan or cluster diff before approval, and the review automation behind it has run \textbf{three and a half years}. Cut the checks guarding every commit from \textbf{about seven seconds to 59 milliseconds} by rewriting the hot paths in Go and moving them from CI into the commit
\item Built the gateway that lets AI assistants reach Argo CD, Grafana and Prometheus through the identity engineers already hold, \textbf{read-only in production and no new credentials}, and encoded change review into supervised playbooks that merge only what they prove safe
\item Led the design and build of a cell-based architecture where one command creates a complete environment, network, cluster, identity and delivery alike, and a second destroys it, refusing to drop state until it verifies nothing still runs. Each cell is its own failure domain, so an incident cannot leave it, and a new region went from \textbf{a multi-week project to one reviewed change}
\item Re-modeled live production networking \textbf{without changing a single running route}. Routes tracked by list position, where editing one address range could destroy and recreate a live one, moved onto explicit resources by proving an empty plan at each step, then onto a policy-defined backbone that keeps environments separated
\item Turned the shared infrastructure code into an internal product with versioned modules, a private registry and golden paths, so teams provision their own environments instead of filing tickets. Creating a team, with repositories, chat, on-call and alerting, went from \textbf{a multi-day chore to one reviewed file}
\item Replaced quarterly patching drills with continuous reviewed flows across container images, dependencies, cluster versions and machine images, rotating nodes in working hours rather than overnight. Brought clusters \textbf{years behind to current in six weeks} and cleared a security backlog built up over \textbf{months in a matter of weeks}
\item Removed a company-wide vendor registry bill with an in-cloud mirror and admission-time image rewriting: no manifests edited, no migration day, and it has \textbf{held for eighteen months}. \textbf{Halved the per-gigabyte cost of the default egress path} with self-managed routing that fails back automatically, contributing the fixes upstream. Consolidated an acquisition onto the platform \textbf{in two months}, closing a second cloud account
\par\smallskip
\textbf{Core}: AWS (EKS, Lambda, Step Functions, Cloud WAN, ECR, IAM), Kubernetes, Argo CD, Flux, Karpenter, Kyverno, Terraform, Terramate, Atlantis, GitHub Actions, pre-commit, Renovate, Vault, Kafka, MCP, Python, Go
\end{itemize}
