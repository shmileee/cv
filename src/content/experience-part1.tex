\cvevent{Senior Site Reliability Engineer}{Two Hundred, consulting for a global SaaS leader in construction IoT}{August 2022 -- Now}{Remote, Denmark}
\begin{itemize}
\item Own the platform a few hundred engineers ship through, in front of a product serving thousands of requests per second. Joined when infrastructure was still changed by hand
\item \textbf{Made every change reviewable.} Moved all infrastructure onto pull requests that show what will happen -- the plan for cloud resources, the exact cluster diff for everything else -- and only then turned on automatic deployment. The review bot I wrote for that is still commenting on pull requests three and a half years later
\item \textbf{Environments on demand.} Designed and built cell-based architecture: one command creates a self-contained environment -- network, cluster, identity, delivery -- and one command proves it is gone, refusing to forget it while anything still runs. A new region became a reviewed change instead of a multi-week project
\item \textbf{Rebuilt the network nobody dared touch.} Moved live production routing onto explicit, reviewable resources without applying a single change, then onto a policy-defined network where environments are genuinely separated
\item \textbf{Turned the shared Terraform estate into a product.} Golden paths teams could actually follow: released and changelogged modules, a layout scaling to hundreds of environments, an internal registry, and the source code, chat, on-call and service catalogue of a new team created from one reviewed file
\item \textbf{Raised the security posture by making it automatic.} Container images, dependency updates, cluster upgrades and machine patching became continuous flows with a human at the merge gate rather than quarterly fire drills, so staying patched stopped depending on anyone remembering. Secrets moved out of configuration and into a vault, and the checks that once took seven seconds now run in milliseconds, before you commit rather than minutes later in CI
\item \textbf{Put AI to work without new attack surface.} Built the gateway that lets AI assistants reach operational systems through the identity people already have -- read-only in production, no new credentials anywhere -- and encoded change review into supervised playbooks that merge only what they can prove is safe, clearing a months-old backlog roughly twenty times faster than by hand
\item \textbf{Cut cost where it hides.} Moved the whole organisation off Docker Hub onto our own mirror -- no migration day, no manifests to edit, nobody noticed, and the bill went away. Saved thousands a month more on the network path nobody looks at, and made cheaper processors the default. Also absorbed an acquisition onto the platform in a summer, and shipped self-service functions running customer code in isolation
\par\smallskip
\textbf{Core}: AWS, Kubernetes, Terraform \& Terramate, GitOps, Python \& Go
\end{itemize}
